Virtual Network Lab

Overview
Designed and configured a virtual cybersecurity lab using Oracle VirtualBox to explore virtual machine networking and basic connectivity testing.

Lab Environment
- Oracle VirtualBox 7.2
- Kali Linux
- Metasploitable2

Network Setup
Configured a shared NAT Network named `myNat network` to enable communication between virtual machines.

Practical Implementation
- Configured virtual machines.
- Set up NAT Network connectivity.
- Identified IP addresses using Linux networking commands.
- Tested connectivity using ICMP ping.

Verification
Successfully tested connectivity between Kali Linux and Metasploitable2.

Project Evidence
Screenshots, network diagrams, commands and detailed configuration notes are available in this repository.

## Security Considerations
Metasploitable2 is intentionally vulnerable and was used in an isolated lab environment.
