# cybersecurity-home-lab
A hands-on beginner cybersecurity project built using oracle virtualbox.

OBJECTIVES:
1. Understand virtual machine configuration.
2. Practice basic networking.
3. Explore kali linux and linux fundamentals.
4. Learn basic network security and lab isolation.

TOOLS AND TECHNOLOGIES:
1. Oracle VirtualBox
2. Kali linux
3. Metasploitable2
4. NAT Network

PRACTICAL ASSIGNMENTS:
Assignment    Topic      
1.            Virtual Lab Setup
2.            Kali linux Exploration
3.            Linux File System
4.            Linux Command line
5.            Secure Lab configuration

REPOSITORY STRUCTURE
Documentation, screenshots, network diagram and practical commands will be organized.
